# JIET Exam Prep

A modern exam-preparation portal for JIET students.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Lucide Icons

## Vision

Semester-wise syllabus, notes, important questions, previous year papers, quizzes and exam-focused revision resources.

Google Drive will be used for the actual study-file storage in the later content layer.
